# 🎵 Spotify Clone

A responsive web-based Spotify clone that simulates user authentication (login/signup), support, premium, and main application dashboards.

---

## ✨ Features
* **Multi-Page Experience:** Includes distinct layouts for onboarding, main player, authentication, support, and premium tiers.
* **Authentication Screens:** Dedicated custom-styled login and signup forms.
* **Loading Sequence:** A smooth transitional loading screen layout.
* **Spotify-Inspired Aesthetics:** Dark theme UI matching the original application interface.

---

## 🛠️ Tech Stack
* **HTML5:** Page structure across multiple application views.
* **CSS3:** Custom styling, dark mode configuration, and `auth.css` for form elements.
* **JavaScript:** Functional UI behaviors and core project interactivity (`script.js`).

---

## 🚀 Getting Started

Follow these steps to run the repository on your local computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory:**
   ```bash
   cd Spotify_Clone
   ```

3. **Launch the project:**
   * Open `index.html` or `start.html` in your web browser. 
   * Alternatively, use a VS Code extension like **Live Server** to run it smoothly.

## 📁 Repository Structure

Based on the core project files:

```text
Spotify_Clone/

├── support.html     # Help/customer support interface

```
